# Установка и запуск Дамира

Инструкция относится к версии проекта с запуском из текущей папки и командой
`damir` без аргументов. Если вы работаете с `develop`, убедитесь, что изменения
этой версии уже в неё влиты.

Для работы нужны интернет, Docker Desktop, Git и доступ к аккаунту ChatGPT.
Отдельно устанавливать .NET SDK на компьютер для запуска Дамира не требуется:
он используется внутри Docker при сборке. Для сборки проектов, с которыми работает
Дамир, внутри его контейнера команд могут понадобиться дополнительные инструменты.

## macOS

1. Установи и запусти [Docker Desktop для Mac](https://docs.docker.com/desktop/setup/install/mac-install/), выбрав версию для Apple silicon или Intel. Дождись его запуска.
2. Открой Terminal и проверь Docker и Git:

   ```bash
   docker --version
   docker compose version
   git --version
   ```

   Если Git отсутствует, macOS предложит установить Command Line Tools. После установки повтори проверку.
3. Скачай репозиторий и открой его папку:

   ```bash
   git clone -b develop https://github.com/PashochekL/Personal-AI-Agent.git
   cd Personal-AI-Agent
   ```

   Если репозиторий уже скачан, перейди в его папку. Для приватного репозитория потребуется доступ к нему на GitHub.
4. Установи команду и выполни первый вход:

   ```bash
   ./install-damir
   ./damir login
   ```

   Вход покажет ссылку и одноразовый код: открой ссылку и введи код на странице OpenAI. При необходимости сначала разреши вход по коду устройства в настройках безопасности аккаунта. Не отправляй код или токены другим людям.
5. Если установщик сообщил, что `~/.local/bin` нет в `PATH`, открой файл `~/.zshrc` в текстовом редакторе и добавь строку:

   ```bash
   export PATH="$HOME/.local/bin:$PATH"
   ```

   Сохрани файл и открой новый терминал. Если установщик сообщил, что команда установлена и доступна, этот шаг не нужен.
6. Перейди в папку проекта и запусти Дамира:

   ```bash
   cd "/путь/к/Todo List"
   damir
   ```

## Windows

Windows-скрипт проверяется с поддельным Docker, включая разделение памяти папок
и сохранение памяти при смене сессии. Полный пользовательский запуск с входом
в аккаунт на Windows необходимо проверить отдельно.

1. Установи и запусти [Docker Desktop для Windows](https://docs.docker.com/desktop/setup/install/windows-install/). Настрой Linux-контейнеры; Docker может попросить установить или настроить WSL 2 согласно инструкции установщика.
2. Установи [Git для Windows](https://git-scm.com/install/windows) и [PowerShell 7](https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-windows).
   Команду `damir` можно вызывать и из Windows PowerShell 5.1: `damir.cmd`
   запускает внутренний `damir-launcher.ps1` в локальном `.dotnet/tools/pwsh.exe`
   или PowerShell 7 из PATH. Вход через `.cmd` не перехватывается скриптом с
   тем же именем. Установка локальной копии
   не входит в обычный git clone; если её нет, нужен установленный PowerShell 7.
3. Проверь зависимости:

   ```powershell
   docker --version
   docker compose version
   docker info --format '{{.OSType}}'
   git --version
   pwsh --version
   ```

   Для `docker info` ожидается `linux`; версия PowerShell должна быть не ниже 7.
4. Скачай репозиторий и открой его папку:

   ```powershell
   cd $HOME
   git clone -b develop https://github.com/PashochekL/Personal-AI-Agent.git
   cd Personal-AI-Agent
   ```

   Если репозиторий уже скачан, перейди в его папку. Для приватного репозитория потребуется доступ к нему на GitHub.
5. Выполни первый вход:

   ```powershell
   .\damir.cmd login
   ```

   Открой показанную ссылку и введи одноразовый код на странице OpenAI. При необходимости разреши вход по коду устройства в настройках безопасности аккаунта. Не отправляй код или токены другим людям.
6. Чтобы команда `damir` работала из других папок, добавь полный путь к папке `Personal-AI-Agent` в **пользовательскую** переменную `Path` через окно «Переменные среды» Windows. Добавь новую строку, не заменяя существующие значения. Затем открой новый терминал.
7. Перейди в папку проекта и запусти Дамира:

   ```powershell
   cd "C:\путь\к\Todo List"
   damir
   ```

## После установки

Обычный `damir` использует общий HTTP backend с очередью. Команды, восстановление
сессии и повторы описаны в [CLI.md](CLI.md). `damir backend` запускает backend
отдельно с портом на loopback; API описан в [BACKEND.md](BACKEND.md).

- Docker Desktop должен быть запущен. Первая сборка может занять время: Docker скачивает образы.
- Для долговременной памяти первый запуск также загрузит локальную модель
  эмбеддингов (около 622 МБ); официальный образ Ollama занимает несколько гигабайт.
  Модель и записи сохраняются в отдельных Docker-томах. Настройки и примеры
  использования описаны в [SANDBOX.md](SANDBOX.md#долговременная-память).
- Дамир получает доступ на чтение и запись к выбранной папке и её файлам. Он может читать `AGENTS.md` в ней. Команды выполняются в контейнере без дополнительного подтверждения и могут менять или удалять файлы выбранного проекта.
- Для каждой папки создаётся своя API-сессия. Если перенести или переименовать папку, для нового пути начнётся новая история. Запуск из самого каталога `Personal-AI-Agent` использует `workspace`. При первом переходе с прямой демо-консоли начинается отдельная API-история; прежняя история остаётся в БД.
- В диалоге `/help` показывает команды, `/context` — процент занятого рабочего бюджета, `/tokens` — расход токенов диалога, `/compress` сжимает контекст, `/skill имя` выбирает навык для следующего сообщения, `/exit` завершает работу.
- Если перенести репозиторий Дамира, на Mac потребуется обновить ссылку на команду, а на Windows — путь в `Path`.
